# 端到端组合优化（decision-focused）：把 Sharpe 直接当损失反传

> 传统做法是「先预测收益的一阶矩（最小化 MSE）→ 再把预测丢进优化器出权重」。
> 但 **MSE 不是决策目标**：预测误差的分布、截面对排序的敏感度、换手成本，都不在 MSE 里。
> 于是出现「预测更准、组合更差」的错配。
> 本模块把 **打分 → 权重 → 组合日收益（含成本）→ 年化 Sharpe** 整条链路做成可微的，
> 直接对 Sharpe 反传（Moody & Saffell 的 direct reinforcement / 近年称 decision-focused learning）。

---

## 1 四种目标，只换损失

网络、组合层、种子、切分、成本全部相同，**唯一变量是损失**：

| 臂 | 损失 | 含义 |
|---|---|---|
| `mse` | `MSE(score, y1)`（y 按日 1%/99% 缩尾） | 两阶段的第一步：先把收益预测准 |
| `ic` | `−Pearson(score, rank(y1))` | 把排序放到标签侧的**精确** RankIC 损失 |
| `sharpe` | `−Sharpe(组合净收益序列)` | **端到端**：直接优化风险调整后的收益 |
| `ret` | `−mean(log(1+r))·252` | **端到端**：直接最大化**年化几何收益**（不带波动惩罚） |

## 2 三个实现要点（少一个就跑不出像样的结果）

1. **组合层必须可微**：`top-k 选股 + 组内 softmax 加权`。
   若用「等权 top-k」，权重对分数是分段常数 ⇒ 梯度为 0，端到端退化成"只学选谁"。
2. **必须截断权重集中度**：组内 z 分数截到 ±3 再 softmax。
   不截断时实测出现过**单票 51% 权重**，80 只组合的日收益被推到 +29%（不可能值）。
3. **成本要进损失**：`c·Σ|w_t − w_{t−1}|`（单边 15bp）。
   否则模型没有"少动"的动机，年化换手会达到 100 倍以上。

## 3 数据卫生（这一段比模型更重要）

面板里 `|y1| > 30%` 的格子中，**85% 是上市不足 60 个交易日的新股**（首日无涨跌幅限制、复牌跳空），
最大单日收益达 **+2004%**。不处理时，任何等权组合的日收益都会出现 +29% 这种不可能值。

因此可交易池（全部只用 ≤ t 的信息）：
`非 ST · 非停牌 · 非当日涨停 · 上市 ≥ 60 个交易日 · 近 20 日未停牌 · y1 有限`。

## 4 结果（2025-01-24 ~ 2026-10-08，409 个交易日，3 种子平均）

| 臂 | 年化 | 波动 | **Sharpe** | 种子间 sd | MDD | **RankIC** | 年化换手 |
|---|---|---|---|---|---|---|---|
| 两阶段 MSE | 20.1% | 20.4% | 0.98 | 0.20 | -29.5% | **0.0791** | 40 |
| RankIC 损失 | 18.8% | 19.8% | 0.95 | 0.64 | -28.4% | **0.0883** | 47 |
| **端到端 Sharpe** | 33.7% | 20.4% | 1.65 | 0.31 | -24.9% | 0.0596 | 44 |
| **端到端 年化收益** | **54.1%** | 23.3% | **2.32** | 0.19 | **-20.2%** | 0.0582 | 44 |
| 全市场等权（未计成本） | 18.9% | 22.4% | 0.84 | — | -21.9% | — | — |

> 表里的 Sharpe 是「三种子平均日收益」的 Sharpe；括号外的种子间 sd 是**逐种子 Sharpe** 的离散度。

**三点读法**

1. **IC 排序 ≠ Sharpe 排序**：IC 最高的臂（0.0883）Sharpe 只有 0.95；IC **最低**的臂（0.0596）Sharpe **1.65**。
   这就是「预测准」与「组合好」不是一回事的直接证据。
2. **相对两阶段 +0.67 Sharpe**（逐种子差 +1.01 / +0.40 / +0.59，3/3 同向，t≈3.7）；
   相对全市场等权 +0.81，且回撤更小（-24.9% vs -21.9% 略大）。
3. **但两阶段只比等权高 0.14 Sharpe** —— 在 55 列量价特征上，预测端的边际价值本来就很薄。
4. **「最大化收益」比「最大化 Sharpe」还猛**：年化 54.1% vs 33.7%，Sharpe 2.32 vs 1.65，回撤反而更小（-20.2% vs -24.9%），
   种子间 sd 也只有 0.19。说明在这段样本里**波动惩罚是有代价的**——Sharpe 目标为了压低分母，放弃了太多分子。
   但这条臂的 IC 同样最低（0.0582），且没有波动约束，**过拟合收益目标的风险也最大**，不能只看年化。

## 5 复现

```bash
# 单跑
python train.py --arm sharpe --seed 42

# 四臂 × 三种子（≈9 分钟，CPU）
bash run_all.sh

# 汇总出净值曲线 + 指标表
python backtest.py
```

数据目录用环境变量指定（默认 `<上级目录>/panel`、`<上级目录>/feat`）：

```bash
SF_PANEL=/path/to/panel SF_FEAT=/path/to/feat python train.py --arm sharpe
```

产出：`E2E-Sharpe-策略净值-<时间戳>.png`、`e2e_metrics.csv`、`e2e_<arm>_s<seed>.json`。

## 6 局限（别把这张图当实盘预期）

- **只有 3 个随机种子**，`ic` 臂的种子间 sd 高达 0.64 ⇒ 该臂与端到端的差异在噪声内；只有"对两阶段"的差异是 3/3 同向的。
- **单段测试、且 epoch 是在验证集上按 Sharpe 选的** ⇒ 测试指标偏乐观，未做多重比较校正。
- 80 只等权 + 10 日调仓，**未计冲击成本与容量**；15bp/边只是粗估。
- `topk / temp / rebal / cost` 未做敏感性扫描，这四项都可能改变排序。
